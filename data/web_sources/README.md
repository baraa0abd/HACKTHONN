# مجموعة مصادر التلوث الضوئي على الويب

شغّل الجامع بالأمر:

```powershell
python scrape_sources.py
```

الملفات الناتجة:

- `sources.json`: حالة كل مصدر، وقت الاسترجاع، بصمة HTML، الأقسام والروابط.
- `sections.csv`: صف لكل قسم نصي، مناسب للفهرسة والتحليل.
- `model_prompt.json`: حزمة JSON جاهزة لنظام استرجاع أو نموذج، مع قواعد تمنع اعتبار التوثيق قياسات.
- `manifest.json`: بصمات SHA-256 وحالة كل مصدر.

`ok` يعني نجاح الاستخراج، و`metadata_only` يعني أن الصفحة تطبيق ديناميكي، و`blocked_by_robots` يعني أن الموقع منع الجمع الآلي ولم يحاول الجامع تجاوزه.

هذه نصوص توثيقية وليست قياسات VIIRS أو SQM. يجب استخدام منتجات NASA العلمية وسجلات Globe at Night وفق شروط المصدر للحصول على القياسات.
